# Documentação Automação Azure

Bem-vindo à documentação oficial dos processos de **automação na plataforma Azure**. Este espaço foi criado para centralizar informações, padrões, boas práticas e exemplos práticos que orientam o desenvolvimento, manutenção e evolução das soluções automatizadas no ambiente Azure da nossa organização.

### Objetivo

O principal objetivo desta documentação é **padronizar e simplificar** a criação de recursos e a execução de tarefas operacionais por meio de scripts, pipelines e ferramentas de infraestrutura como código (IaC). Aqui, você encontrará orientações detalhadas sobre:

* Automatização de provisionamento de recursos via ARM, Bicep ou Terraform
* Integração com o Azure DevOps e GitHub Actions
* Uso de Runbooks no Azure Automation
* Scripts PowerShell e CLI para tarefas recorrentes
* Aplicação de políticas automatizadas (Azure Policy)
* Governança, controle de custos e segurança em ambientes automatizados
